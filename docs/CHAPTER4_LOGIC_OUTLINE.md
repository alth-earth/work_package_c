## 1. 第四章逻辑摘要（约 500 字）

**研究对象**：北极航道船舶在时变冰—浪—风耦合环境下的动态气象导航方法。研究对象为"风险约束下的时空航路优化算法"及其在弱通信条件下的边缘决策支撑机制。

**核心科学/技术问题**：传统最短路径方法以几何距离最短为优化目标，忽视了冰—浪—风对船舶有效航速的影响，且静态风险图无法反映船舶抵达某网格时该网格的预测风险。如何在时变预测风险约束下，构造同时考虑航程、航行时间、环境风险、航速损失与不确定性的综合航路代价模型，并在弱通信条件下提供可执行的边缘决策摘要，是本章要解决的核心问题。

**数据输入**：第三章输出的多时效风险预测产品——含 `risk_mean`（连续风险代价）、`risk_level`（风险等级）、`hard_mask`（不可航行区域）、`uncertainty`（预测可信度）、`reason_code`（主要风险来源），以及多源环境观测（海冰密集度、冰厚、冰漂、风浪流、能见度、水深、通航密度）。本章使用的真实数据为北极冬航窗口的 145 帧风险预报序列（holdout 2026-02-22 与 development 2026-03-22 两独立窗口）。

**核心方法**：本章构建风险-速度-ETA 三方耦合的不动点边代价模型，将"船舶到达某网格时的预测风险"映射到该航段的可达速度与航行时间，再以综合航路代价（距离+时间+风险+航速损失+不确定性）驱动风险约束航迹规划。算法层面，本文采用时间依赖 A\* 算法在时间展开状态图上搜索，并以 admissible 启发式压缩搜索空间。

**模块数据流与因果逻辑**：多源环境与状态输入 → 时空状态构建 → 风险预测 → 风险代价场（含 hard_mask 与 uncertainty）→ 风险约束航迹规划（产出多模式航路与多时效候选方案）→ 在线重规划与控制接口 → 仿真验证。其中"误差反馈 → 风险场更新 → 规划参数修正"构成闭环。

**输出结果**：多模式气象航路（安全优先 / 效率优先 / 均衡推荐）+ 事件触发的动态重规划建议 + 弱通信条件下的关键风险摘要。

**验证方法**：以无信息 Dijkstra、静态场 A\*、风险无关基线为对照，在真实 145 帧风险预报序列与合成 4 档规模上进行配对比较；以消融研究验证各模块贡献；以反向论证验证改进候选未超越当前实现。

**本章最终需要证明的结论**：(1) 在真实北极 145 帧冰情上，相比静态场规划，本文方法的最大航段风险降低 15.3%–29.8%、平均航段风险降低 10.7%–16.5%；(2) 相比无信息 Dijkstra，扩展状态数减少 55.7%–86.6%、加速 2.16×–7.65×，且总代价严格相同，证明启发式加速未牺牲最优性；(3) 真实北极海洋数据违反 FIFO 性质（两窗口 43 500 / 40 776 次 interval 级违反），证明传统时依赖最短路支配剪枝在真实数据上不安全，本文采取"先证明、后启用"的保守工程纪律。

- 可编辑PNG/SVG、航路CSV、风险CSV和元数据位于 `.runtime/experiments/c-chapter4-route-map/`，源摘要或事件链漂移时绘图脚本失败闭锁。

### 6.2 `no_replanning` / `no_correction` 独立消融档

- 正式 `plan()` 默认就是**单次规划**，replanning baseline 是单独验证产物，与 `plan()` 默认路径正交。
- 在正式 control 下不存在"再剥一层重规划"的独立语义。
- 消融表4-4 严格只列 4 档（full / no_risk / no_heuristic / no_temporal），备注"重规划 baseline 与 `plan()` 默认路径正交"。

### 6.3 参数敏感性研究

- `planner_config.time_bucket_minutes / edge_sample_count / max_risk_frame_gap_minutes` 等参数有配置开关，但**无系统化扫参实验数据**，SSOT 也未记录 sweep 矩阵。
- 构建敏感性需 4-5 个参数笛卡尔积扫描，每组合保留 raw 数据，预算超出本轮。
- 替代：在 §4.6 实验设计中声明"实验设置一致"。**第四章不画敏感性图**。

### 6.4 development 24h 上 `risk_blind` 与 `recommended` 路线重合

- development 窗口 risk 权重不起决定性作用，**真实数据特征**，非缺失。
- 规范算例图4-5/4-7明确标注 `dev / risk_blind ≡ recommended`，避免读者误判样本偏差。
- 扩样本（2026-09-01，104 算例，主报告 §12）后，risk_blind 已加入全部算例并给出约 239 个可比较单元的动机证据分布；**不再只有 n=1**。单算例图仍保留 n=1 标注。

## 7. 论文正文写作的注意事项（从约束文件提取）

1. **学术论文风格**：使用"本文构建……"、"实验结果表明……"、"由图4-X可知……"，禁止"团队完成了"、"工作包A/B/C"、"runner/script"。
2. **图表优先**：先给数据/图表 → 描述现象 → 量化差异 → 分析原因 → 局部结论。禁止先写"本算法显著优于"再找数据。
3. **图题在下，表题在上**；公式按 (4-1)、(4-2) 编号；所有图表必须在正文中被引用。
4. **公平性约束**：先检查输入/起终点/风险场/可行域/目标函数/终止条件/硬件/随机种子/先验信息/精度差异，再宣称性能优劣。
5. **数据诚实**：n=1 必须标注"该结果仅用于现象说明，不构成统计意义上的性能结论"；失败实验可作为反向论证/正确性边界/设计选择依据。
6. **本章小结约 400-600 字**：按"问题→方法→数据结果→核心发现→对下一章接口"组织，引用定量结果，不用"首先、其次、最后"罗列软件任务。
7. **结构图风格**：白底、深蓝标题、浅蓝/浅青/浅绿/浅黄填充、深蓝细边框、圆角矩形、蓝色虚线边界、明确方向箭头、一级模块突出、输出模块单独色块；不使用 3D、阴影、渐变、PPT 风格。
8. **算法结果图风格**：白底、坐标轴清晰、字号统一、单位完整、图例简洁、误差棒/置信区间/样本量 n、同一章不同图算法颜色/线型语义一致。
