# 验收清单

## 自动验收

```bash
make env-create
make lock
make sync
make check
make demo
```

`make check` 必须同时通过 Ruff、pytest、`uv lock --check`、`uv sync --check` 和 CLI help。

## 关键不变量

- 非 UTC 时间、超范围/形状错误、上下文不匹配或正式来源未防未来泄漏时，`RiskFrame` 明确拒绝。
- ETA 整点、帧间、超窗口、超间隔和硬掩膜行为有手算单元测试。
- 小网格上 A* 与零启发式 Dijkstra 同成本；路线按 ETA 而非单帧风险变化。
- 任意发布路线的硬约束违规数为 0，距离/ETA/风险可复算。
- 时间、数据、风险、偏航、事件/人工触发以及最小间隔/迟滞/收益阈值有测试。
- seek 后旧代次、同代次旧 revision 和已取消工作无法覆盖 CD latest。
- 真实旧交付包仅通过隔离适配层读取，且保留低可信、未知 `issue_time` 和速度因子缺失警告。
- 两条场景使用同一个配置加载器和规划核心，不在求解器中硬编码路线。

## 交付限制

1. 旧 B 只有稀疏、不规则风险时刻，不满足正式的逐小时全航程输入；C 会拒绝超间隔采样。
2. 旧 `sea_mask` 只能证明陆地约束，不能证明冰区、净水深、禁航区等完整硬约束。
3. 当前船型和成本权重未经真实标定；结果只能称为演示路线。
4. v1 不实现等待、非 FIFO 标签设置、D* Lite、MPC 或真实航海导航规则。
